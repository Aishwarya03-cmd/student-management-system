
# EduTrack - Student Management System

A modern and responsive Student Management System developed to manage student records efficiently.

## About the Project

EduTrack is a web-based application designed to simplify student record management. It provides an easy-to-use dashboard where users can add, view, update and delete student information.

## Features

- Modern Dashboard
- Total Student Statistics
- Add New Students
- View Student Records
- Edit Student Details
- Delete Student Records
- Search Students
- Student Status Management
- Responsive Design

## Technologies Used

## Database

Database Name: student_management

Table Name: students

The database stores:
- Student ID
- Student Name
- Email Address
- Course
- Student Status
- Registration Date

## Installation

1. Download or clone this repository.
2. Set up a PHP and MySQL environment.
3. Import database.sql into MySQL.
4. Configure database credentials in config.php.
5. Run the project using a PHP-enabled web server.
